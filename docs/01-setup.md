# 01. Установка и запуск

## Назначение проекта

**ZooPark: Tau Ceti** — это комплексный градостроительный симулятор зоопарка, разрабатываемый на движке Godot 4. 

Проект объединяет несколько ключевых систем:
- Глубокую экономику (управление средствами, персоналом, запасами еды).
- Оптимизированный открытый мир, построенный на стриминге чанков (`ChunkManager`), который позволяет загружать и выгружать участки карты в реальном времени.
- Разнообразные игровые механики для строительства вольеров и заботы о животных.
- Полноценную поддержку контроллеров, кастомный UI и систему сохранений.

Проект структурирован так, чтобы отделить глобальную логику (Autoloads в папке `core/`) от конкретных игровых элементов (сцены в папке `features/`).

---

## Требования к окружению

| Инструмент | Версия |
|---|---|
| Godot Engine | 4.6 (или любая совместимая 4.x ветка с поддержкой Forward+) |
| Физический движок | Godot Jolt (задан в `project.godot`) |
| Система контроля версий | Git |

> **Примечание:** Проект использует современные возможности GDScript и многопоточность для подгрузки мира, поэтому старые версии Godot 3.x не подойдут.

---

## Конфигурация и данные

### Локальные сохранения
Система чанков и глобальных сохранений (`GameSaveSystem`) записывает данные в локальную папку пользователя ОС (директория `user://` в Godot).

Пути по умолчанию:
- **Windows:** `%APPDATA%\Godot\app_userdata\ZooPark\`
- **Linux:** `~/.local/share/godot/app_userdata/ZooPark/`
- **macOS:** `~/Library/Application Support/Godot/app_userdata/ZooPark/`

При отладке сохранений или сбросе прогресса, очищайте эту директорию.

## Установка и запуск

### 1. Загрузка исходного кода

Склонируйте репозиторий в удобную директорию:

```bash
git clone <URL_репозитория>
cd zoo-park
```

### 2. Импорт в Godot

1. Откройте **Godot Project Manager**.
2. Справа нажмите кнопку **Import**.
3. В появившемся окне укажите путь к файлу `project.godot`, который находится в корне склонированной директории.
4. Нажмите **Import & Edit**.
5. *При первом открытии Godot выполнит импорт всех ресурсов, текстур и аудиофайлов в папку `.godot/`. Это может занять некоторое время.*

### 3. Запуск игры

Проект уже преднастроен: главная сцена указана в конфигурации (`res://features/ui/splash/splash_screen.tscn`).

- Нажмите `F5` на клавиатуре или иконку **Play** (Треугольник) в правом верхнем углу редактора.
- Приложение запустится, покажет Splash-экран и перейдет к основному интерфейсу.

### Быстрая проверка работы систем
1. В запущенной игре проверьте навигацию по UI (мышь или геймпад).
2. Убедитесь, что ошибки отсутствуют во вкладке **Output** (или консоли).
3. При необходимости включите `PerformanceMonitor` в настройках, чтобы отслеживать FPS и потребление памяти.
