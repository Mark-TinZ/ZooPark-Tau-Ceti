# ZooPark: Tau Ceti

Проект градостроительного симулятора зоопарка на движке `Godot 4`.

Приложение совмещает:

- Игровую экономику (деньги, популярность, персонал).
- Динамическую систему чанков с многопоточной загрузкой и сохранением для бесшовного открытого мира.
- Различные игровые механики (строительство вольеров, управление животными и сотрудниками).
- Систему сохранений, настроек и мониторинга производительности.

README описывает фактическое состояние репозитория на текущий момент, включая реализованные возможности и архитектуру.

## Назначение проекта

Проект представляет собой симулятор управления зоопарком, включающий следующие сценарии использования:

- Управление экономикой: бюджет, популярность, запасы еды, покупка и развитие.
- Стриминг игрового мира: асинхронная загрузка и выгрузка участков карты (чанков) в реальном времени.
- Управление сущностями: животные, сотрудники, вольеры, административные и декоративные здания.
- Удобный интерфейс: главное меню, глубокие настройки, виртуальный курсор, мониторинг производительности и управление камерой.

## Текущий статус

Проект активно развивается. Ниже — картина по состоянию на сейчас.

### ✅ Полностью / Частично реализовано

**Игровые системы (Core):**
- **Менеджер экономики (`EconomyManager`):** Учет средств, смена дней, сигналы об изменении ресурсов (деньги, популярность, еда).
- **Менеджер чанков (`ChunkManager`):** Потокобезопасное асинхронное сохранение (Write-Back Cache) данных для бесшовного мира.
- **Менеджер сохранений (`GameSaveSystem`):** Глобальная система сериализации состояния игры.
- **Менеджер сцен (`SceneManager`):** Удобные переходы между UI и игровыми уровнями.

**Интерфейс и механики:**
- Splash-скрин и Главное меню.
- Настройки (через `SettingsManager`) с поддержкой различных локализаций (ru/en через встроенные `.translation` файлы).
- Управление стилистикой UI через `ThemeManager`.
- Внутриигровой виртуальный курсор (`VirtualCursorUI`).
- Анализ узких мест в реальном времени (`PerformanceMonitor`).
- Настроенный Input Map для клавиатуры и геймпада (перемещение камеры, зум, вращение).

## Технологический стек

- `Godot Engine 4.6` (Forward Plus)
- `GDScript` в качестве основного языка программирования
- `Jolt Physics` для высокопроизводительной физики

## Требования к окружению

- `Godot 4.6` (или совместимая 4.x версия с поддержкой Forward+).
- Настроенный плагин/модуль `Jolt Physics`.

## Установка и запуск

1. Склонируйте репозиторий.
2. Откройте **Godot Project Manager** и нажмите **Import**.
3. Выберите файл `project.godot` в корне проекта.
4. Откройте проект и нажмите `F5` для запуска (стартовая сцена — `splash_screen.tscn`).

## Архитектура и структура

Проект четко разделен на логические модули для удобства масштабирования:

```text
.
├─ addons/                    # Сторонние плагины (например, Jolt Physics)
├─ assets/                    # Графика, модели, текстуры, звуки
├─ core/                      # Глобальные синглтоны (Autoloads)
│  ├─ chunk_manager.gd        # Асинхронная система чанков
│  ├─ economy_manager.gd      # Игровая экономика
│  ├─ game_save_system.gd     # Сохранения
│  └─ ...                     # Прочие системные менеджеры
├─ features/                  # Логика конкретных игровых механик
│  ├─ buildings/              # Строения и вольеры
│  ├─ camera/                 # Поведение игровой камеры
│  ├─ game/                   # Игровые циклы и правила
│  ├─ ui/                     # Пользовательский интерфейс
│  └─ world/                  # Генерация мира и окружение
├─ localization.csv           # Файл локализации текстов (ru/en)
└─ project.godot              # Конфигурация проекта
```

## Разработка и вклад в проект

Правила командной работы описаны в `CONTRIBUTING.md`. Ключевые моменты:

- перед началом работы синхронизируйтесь с `main`;
- используйте отдельную ветку под каждую задачу;
- изолируйте логику фичей в папке `features/`, а глобальные системы в `core/`;
- для связи модулей используйте систему сигналов Godot.

Более подробная документация находится в директории `docs/`.
